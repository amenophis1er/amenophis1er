# Hey, I'm Amen

I build tools for voice, telecom, and the web — mostly in Go and Rust.

## What I'm working on

**[x-phone](https://github.com/x-phone)** — Open-source SIP/RTP libraries and tools. Make and receive real phone calls from code — available in [Go](https://github.com/x-phone/xphone-go) and [Rust](https://github.com/x-phone/xphone-rust), with a self-hosted [voice gateway](https://github.com/x-phone/xbridge) for WebSocket/REST integration.

**[Trokky](https://github.com/Trokky)** — A composable CMS framework for structured content systems. Preparing for open source — the [CLI](https://github.com/Trokky/cli) is already public.

**[oxiclean](https://github.com/getoxiclean/oxiclean)** — macOS storage cleaner. Find and remove hidden bloat — package caches, Docker artifacts, orphaned app data.

**[tts-bridge](https://github.com/amenophis1er/tts-bridge)** — TTS APIs speak HTTP. Voice apps speak WebSocket. This bridges the gap.

**[gh-setup](https://github.com/amenophis1er/gh-setup)** — Declaratively configure GitHub repos and settings from a YAML file.
